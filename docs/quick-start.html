Quick Start

Run the core PlantVelocity workflow from corrected spliced and unspliced counts to an RNA velocity embedding.

Before you begin¶

You need:

  • PlantVelocity installed in R.
  • A Seurat v5 object containing PCA and UMAP embeddings.
  • A loom file generated by the upstream plantvelo workflow.
  • Matching cell and gene identifiers between the Seurat object and the loom file.

In the examples below, seob is an existing Seurat object and plantvelo_output.loom is the path to the corresponding loom file.

Create a PlantVelocity object¶

Load PlantVelocity and combine the Seurat object with the corrected count layers:

R
library(PlantVelocity)

pv <- create_plantvelo(seurat_object = seob, loom_path = "plantvelo_output.loom")

The resulting plantvelo object retains the cell metadata and dimensional reductions from Seurat. Spliced and unspliced counts are used for velocity inference. IR-associated counts, when present, are stored separately and do not enter kinetic fitting.

Compute RNA velocity¶

Construct the neighbour graph, smooth the count layers and fit the two-state kinetic model:

R
pv <- build_neighbor_graph(pv, n_neighbors = 30, n_pcs = 30)
pv <- compute_moments(pv)
pv <- recover_dynamics(pv, n_top_genes = 2000)
pv <- compute_velocity(pv)
pv <- compute_velocity_graph(pv)
pv <- compute_velocity_embedding(pv)

PlantVelocity fits each selected gene independently. Genes that do not contain sufficient information or produce invalid fitted parameters are marked as unfitted and excluded from velocity calculation.

Visualize the velocity field¶

Project the velocity field onto the UMAP embedding:

R
plot_velocity_embedding(pv, reduction = "umap", group_by = "cell_type")
plot_velocity_stream(pv, reduction = "umap", group_by = "cell_type")
plot_velocity_embedding_grid(pv, reduction = "umap", group_by = "cell_type")

Replace "cell_type" with a metadata column available in your Seurat object. Omit group_by to plot cells without metadata-based grouping.

What the workflow produces¶

After completing the workflow, the plantvelo object contains:

  • Smoothed spliced and unspliced expression moments.
  • Fitted transcription, splicing and degradation parameters.
  • Gene-wise RNA velocity estimates.
  • A directed cell-to-cell velocity graph.
  • Velocity vectors projected onto the selected embedding.

IR-associated signals remain separate from the two-state velocity model and can be examined independently.
